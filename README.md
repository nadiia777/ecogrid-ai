# EcoGrid AI
Хмарний сервіс та мобільний застосунок для автоматичної оптимізації витрат на електроенергію
та керування резервним живленням (інвертори, акумулятори, сонячні електростанції).

## Основні модулі
- **Telemetry & Inverter Adapter**: збір стану батареї, потужності та статусу мережі через API інверторів.
- **Tariff & Forecast Engine**: аналіз зонних тарифів, графіків та прогнозу погоди для планування заряджання.
- **Mobile App (iOS/Android)**: моніторинг економії, керування режимами та сповіщення.

## Робочий процес (Git Workflow)
- Основна гілка `main` містить перевірений та стабільний код.
- Нові задачі розробляються у гілках `feature/<short-task-name>` та інтегруються через Pull Request із Code Review.
